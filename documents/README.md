## Authority Boundary

The durable engineering contracts live under `documents/`; current delivery
state and dated closure evidence live only in the development plan. The root
[README](../README.md) is the operator-facing orientation layer and retains
its current binding CLI/project contract until Phase `3` completes the explicit
authority transfer. These execution contracts label unimplemented target behavior;
planning changes do not establish safe execution or hardware qualification.
